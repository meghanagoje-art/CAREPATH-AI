CAREPATH AI — README

Project Overview

CAREPATH AI is a patient case-taking platform designed for SIH 2026 (Problem Statement 26047). It collects structured patient history before consultation using multilingual voice + touch interaction, adaptive AI questioning, document OCR, structured summaries, red-flag detection, and secure pre-arrival hospital communication.

Proposed Tech Stack

  • Frontend: Next.js 14 + React + TypeScript + Tailwind CSS
  • Backend: FastAPI (Python)
  • Database: PostgreSQL
  • Auth: JWT (OAuth2 / HTTP-only cookies)
  • Charts: Recharts (production) / Chart.js (this demo)
  • OCR: Tesseract / AWS Textract / Google Document AI
  • Voice: Whisper API / Azure Speech Services
  • Hospital Integration: HL7 FHIR / HTTPS webhooks
