# MiMo-V2.5 — CAREPATH AI

This archive contains the complete CAREPATH AI SIH 2026 browser prototype supplied in the source project.

## Run

1. Extract `MiMo-V2.5.zip`.
2. Open `MiMo-V2.5/index.html` in a modern browser.

No installation, build step, backend, or local server is required. An internet connection is needed when the page opens because Tailwind CSS, Google Fonts, Font Awesome, Chart.js, and QRCode.js are loaded from public CDNs.

## Included experience

- Patient, doctor/staff, and hospital administrator role views
- Multistep patient intake and consent flow
- Simulated voice case-taking and document OCR
- Structured patient summary and emergency sharing flow
- Hospital dashboard, analytics charts, QR generation, and complete guided demo

## Important

This is a simulated demonstration prototype. It is not connected to real hospital systems, and it must not be used for diagnosis, treatment, or emergency medical decision-making.
